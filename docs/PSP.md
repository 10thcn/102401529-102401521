# PSP2.1 表格

> 预估耗时在**开始编程前**填写；实际耗时在**编程结束后**如实回填。
> 回填时注意：把返工、调试、排查问题的时间也计入对应阶段（例如排查
> "node --test 目录参数报错"的时间计入 Test 阶段），这样 PSP 才能真正
> 帮助我们发现哪些环节低估了。

## 预估依据（简要）

- **具体编码 480 分钟**：4 个页面 + 数据层 + UI 层，按每个页面约 1.5 小时、数据层约 2 小时估算
- **测试 120 分钟**：28 个单元测试用例编写 + 全流程手工走查 + 修复问题
- **需求分析 60 分钟**：主要为学习 node:test 单元测试框架、确认 Chrome file:// 下 localStorage 的行为
- 其余阶段按经验占比估算
