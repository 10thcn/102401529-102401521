# 校园失物招领

2026 秋软件工程第二次结对作业 —— 基于第一次作业原型实现的校园失物招领网页。

面向校园里的失物场景：丢失物品的同学可以发布**寻物**信息，捡到物品的同学可以发布**招领**信息；所有人可以在首页集中浏览、按关键词搜索、按类别/地点/状态筛选；查看详情后可一键复制发布者的联系方式；物品找回或归还后，由发布者将信息标记为"已找到"/"已归还"，减少重复询问和无效联系。

核心流程：**发布信息 → 浏览或搜索 → 查看详情 → 联系发布者 → 更新状态**。

- 纯 HTML + CSS + 原生 JavaScript，**零依赖、零构建**，双击 `index.html` 即可在 Chrome 中运行
- 数据保存在浏览器 localStorage 中，本机持久化、多标签页共享，无需服务器
- 首次打开自动预置 8 条示例数据，方便直接体验搜索、筛选、状态更新等全部功能

## 使用说明

### 运行环境

- **谷歌浏览器（Chrome）**，直接打开本地文件即可，无需安装任何软件
- 可选：安装 [Node.js](https://nodejs.org/)（18 及以上版本）用于运行单元测试；不安装也不影响网页使用

### 运行步骤

1. 下载本项目全部文件（保持上述目录结构不变）
2. 用 Chrome 打开 `index.html`（双击即可，或拖入 Chrome 窗口）
3. 首次打开会自动载入 8 条示例数据，可直接体验下列全部功能

### 操作指南

| 你想做什么 | 怎么操作 |
| --- | --- |
| 浏览信息 | 首页即列表，可点"全部/寻物/招领"标签切换类型 |
| 搜索物品 | 首页顶部搜索框输入关键词（匹配物品名称和描述），即时出结果 |
| 筛选信息 | 搜索框下方的类别/地点/状态标签，可任意组合，点"重置筛选"恢复 |
| 查看详情 | 点击任意信息卡片 |
| 联系发布者 | 详情页底部"联系发布者"→ 弹窗显示联系方式 → 点"一键复制联系方式" |
| 发布寻物/招领 | 底部 Tab 栏"发布"→ 选择寻物或招领 → 填写表单（带 \* 为必填）→ 发布 |
| 查看我的发布 | 底部 Tab 栏"我的" |
| 标记已找到/已归还 | "我的发布"（或自己信息的详情页）→"标记已找到/已归还"→ 确认 |
| 删除信息 | "我的发布" →"删除"→ 二次确认 |

### 状态流转说明（谁来改、在哪改、其他人看到什么）

1. **谁来改**：只有发布者本人可以修改——系统通过本机记录识别"我发布过的信息"（在"我的发布"和详情页出现操作按钮）
2. **在哪改**：两个入口——"我的发布"页的操作行，或自己信息详情页底部的按钮
3. **改完别人看到什么**：寻物信息显示"已找到"、招领信息显示"已归还"；卡片整卡置灰并沉到列表底部；详情页显示"已于 ×× 标记为已找到/已归还"的时间线。状态可随时改回"未解决"

### 常见问题

- **为什么不同电脑/浏览器看到的数据不一样？** 数据保存在各自浏览器的 localStorage 中，互不影响，这符合本次作业"无需服务器"的要求
- **想恢复初始示例数据？** Chrome 打开页面后按 F12 → 控制台执行 `localStorage.clear()` → 刷新页面
- **点复制没反应？** 个别环境会降级为手动复制：弹窗中的联系方式长按/选中后 Ctrl+C 即可
- **数据会不会突然丢失？** 只要不清除浏览器数据、不换浏览器，数据会一直保留；个别受限环境（如隐私模式）会自动降级为内存存储，功能可用但刷新后不保留

## 单元测试

选用 **Node.js 内置的 node:test 模块**（Node 18+ 自带），零依赖、开箱即用：

```bash
npm test          # 等价于 node --test "test/*.test.js"
```

共 28 个测试用例，白盒覆盖数据层（store.js）的各个分支：增删改查、表单校验规则（空值/超长/非法选项/未来时间）、关键词与组合筛选、状态机双向切换、已解决置底排序、相对时间显示、相似信息提醒、示例数据幂等初始化、统计计算。测试结果示例：

